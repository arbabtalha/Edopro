# Edopro

This is helpful for students (for using in Android or iOS) there are around 100 plus features in webapp, when you download it, U can run it totally offline because it have HTML,CSS and JavaScript.

## 📂 The App — Easy Name! 🎉

The app is a single file: **`edopro.html`**

Just download or open **`edopro.html`** — no spaces, no emojis, nothing complicated. Easy to type, easy to remember! 😊

### 🔗 Open it online

If GitHub Pages is enabled for this repo, your link is simply:

```
https://arbabtalha.github.io/Edopro/edopro.html
```

To turn on GitHub Pages: **Settings → Pages → Source → main branch → Save**.

### 💾 Use it offline

1. Download `edopro.html` to your phone or computer.
2. Open it with any browser (Chrome, Safari, etc.).
3. It runs completely offline — 100+ features, all in one file!
